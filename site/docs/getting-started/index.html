Getting started

Make your first extraction.

Developer preview

The packages are not published to npm yet. Package examples below assume you have a local Linkoi checkout and have built the workspace.

Requirements#

Use Node.js 22 or newer and npm. Bun 1.4 is used by the test suite. These instructions run from an existing Linkoi source checkout; a public repository and npm release are not available yet.

sh
npm ci
npm run build
# Optional: run all checks and tests
npm run verify

Extract a URL#

Create example.mjs at the repository root, then run it with node example.mjs.

ts
import { resolve } from '@linkoi/core'

const page = await resolve('https://example.com', {
  timeoutMs: 5000,
  maxBytes: 2_097_152,
})

console.log(page.title ?? page.url)

Use HTML you already have#

ts
import { fromHtml } from '@linkoi/core'

const page = await fromHtml(
  '<title>A small discovery</title>',
  'https://example.com',
  { fallback: false }
)

console.log(page.title)

Set fallback: false when supplied HTML must be parsed without network activity. The optional Metascraper fallback can make additional requests.

Use a local package#

Until publication, build tarballs and install them in your application using a local file path. Keep those archives in your repository if another machine needs to reproduce the install.

sh
npm run pack:local
# In your application, use the path to the generated archive:
npm install /path/to/linkoi/artifacts/linkoi-core-0.1.0.tgz
